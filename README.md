# HTML & CSS College Practical Projects

## 📌 About the Project
This repository contains five beginner-friendly web development projects created using HTML5 and CSS3. These projects demonstrate basic web design concepts, layouts, styling, and responsive design.

## 📂 Projects Included

1. **Student Profile Card** – A profile card with colors, borders, padding, margins, shadows, and hover effects.
2. **College Navigation Bar** – A navigation bar built using CSS Flexbox with Home, About, Courses, Faculty, and Contact links.
3. **Course Section** – Six course cards arranged using CSS Grid with responsive layouts and hover effects.
4. **College Homepage** – A complete college website layout featuring a header, hero section, about section, courses, contact form, and footer.
5. **Responsive Student Dashboard** – A dashboard featuring a sidebar, summary cards, recent activities, and responsive layouts for desktop and mobile screens.

## 🛠️ Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries
- Hover Effects

## ✨ Features
- Clean and simple user interface
- Attractive colors and styling
- Card layouts with borders and shadows
- Interactive hover effects
- Responsive design for different screen sizes
- Beginner-friendly code

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open any `.html` file in a web browser.
4. Alternatively, use the Live Server extension in VS Code.

## 🎯 Learning Objectives
- Understand HTML5 structure and elements.
- Learn CSS properties such as padding, margin, borders, and colors.
- Practice CSS Flexbox and Grid layouts.
- Create responsive web pages using media queries.
- Improve basic front-end web development skills.
